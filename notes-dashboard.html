Obsidian sync

Notes are pushed as markdown files to a GitHub repo that your Obsidian vault syncs with (via the free obsidian-git community plugin). Each note gets a category folder and YAML frontmatter with tags. The token is stored only in this browser.
1.Create a private GitHub repo for your vault (e.g. obsidian-vault)
2.In Obsidian: install the Git community plugin, then clone or publish your vault to that repo and enable auto pull/push
3.github.com → Settings → Developer settings → Fine-grained tokens → generate one scoped to ONLY that repo with Contents: Read and write
4.Paste everything below
