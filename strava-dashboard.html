Connect Strava
A one-time setup so the coach can read your activities automatically. Everything is stored only in this browser. Heads-up: your client secret lives in browser storage — fine for a personal app in single-player mode, and you can rotate it anytime at strava.com/settings/api.
Step 1 — Your app credentials
Go to strava.com/settings/api, create an app (Authorization Callback Domain: your GitHub Pages domain, e.g. username.github.io). Copy the Client ID and Client Secret here.
Step 2 — Paste the code
After you approve access, Strava sends you back here with a code in the address bar. If it didn't auto-fill, copy the value of code= from the URL and paste it below.
